If you encounter an issue with your website, automation script, or Active Directory environment, submitting a support ticket through the portal is the fastest way to get help.

### How to Log an Issue

1. Navigate to the **Support** section of the portal.
    
2. Click **New Ticket**.
    
3. **Be specific:** Provide as much detail as possible. Instead of saying _"the script is broken,"_ say _"the script failed to process the CSV file uploaded at 10:00 AM."_
    
4. **Attach Evidence:** If you have an error message on your screen, take a screenshot and attach it to the ticket.
    

Using the ticketing system ensures your request is logged instantly, prioritized correctly, and routed to the technician best equipped to resolve it.
