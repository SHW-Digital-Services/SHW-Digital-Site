It is completely normal to think of a great new feature or requirement while a project is actively being built. However, because our contracts are based on fixed-price scopes, these changes need to be managed carefully.

### The Change Request Process

1. **Notification:** Let us know what new feature you would like to add to the current build.
    
2. **Assessment:** We will review how this changes the timeline and the technical architecture of the ongoing work.
    
3. **Revised Quote:** We will issue a "Change Order" document detailing the additional cost and the new delivery date.
    
4. **Approval:** You must digitally sign the Change Order before we begin building the new feature.
    

If a requested change is completely different from the original goal, we may advise finishing the current contract first and scoping the new idea as a separate Phase 2 project.
