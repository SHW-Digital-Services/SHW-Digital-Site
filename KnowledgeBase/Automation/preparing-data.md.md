A script is only as good as the data it is given. Before we begin building an automation for your business, taking time to prepare your environment will ensure the project runs smoothly.

### 1. Standardize Your Inputs

If you want a script to read a form, the form needs to be consistent. Ensure that mandatory fields are actually marked as mandatory so the script doesn't break when it encounters a blank space.

### 2. Map the Process Manually

Before automating a workflow, write down every single click and keystroke a human takes to do the job right now. Often, humans make tiny, subconscious decisions (like skipping a file if it looks wrong) that a computer needs to be explicitly taught.

### 3. Prepare Test Data

We will need "dummy" data to test the script safely. Never test a brand-new automation on live client data. Prepare a folder of fake files or test accounts that we can use to verify the script works perfectly before it goes live.
