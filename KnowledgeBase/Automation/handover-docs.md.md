When an automation script is finished, it is completely handed over to your business. We ensure you have everything you need to run it confidently.

### The Handover Package (£35 Add-on)

While simple scripts might be self-explanatory, we highly recommend adding documentation to your project. This includes:

- **Instruction Guide:** Plain-English, step-by-step instructions on how to trigger the script (e.g., how to run it, what folders it looks at).
    
- **Prerequisites:** A list of exactly what software or access levels are needed for the script to run successfully.
    
- **Troubleshooting Steps:** What to check if the script encounters a common error (like a missing file).
    

### Ownership

Once the script is paid for and handed over, you own the code. You are not locked into our systems, and you are free to run the script as many times as you like.
