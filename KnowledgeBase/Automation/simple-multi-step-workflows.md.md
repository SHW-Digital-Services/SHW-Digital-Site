When scoping an automation project, we categorize scripts based on their complexity to ensure you get a clear, indicative starting price.

### Simple Task Scripts (From £150)

A simple script generally performs one straight-line action within a single environment.

- **Example:** A script that automatically renames hundreds of image files in a folder based on today's date.
    
- **Example:** A script that reads a single Excel file and deletes any rows where the email address is missing.
    

### Multi-step Workflows (From £225)

A multi-step workflow connects multiple different actions, often requiring basic decision-making logic or moving between different software tools.

- **Example:** A script that monitors an inbox for a specific email, downloads the attached PDF, uploads it to a specific client folder in SharePoint, and then sends a notification message in Microsoft Teams.
    

The final scope and price will always be confirmed before any work begins, so you know exactly which tier your process falls into.
