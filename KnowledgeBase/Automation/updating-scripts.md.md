As your business grows, the way you work will naturally evolve. The automation scripts we build are designed to be practical, meaning they can be modified later.

### When to Request an Update

You will need to have your script updated if:

- You switch to a new software provider (e.g., moving from Xero to QuickBooks).
    
- You want the script to do an additional task (e.g., it currently sends an email, but now you also want it to send an SMS).
    
- Your data structure changes (e.g., you added five new mandatory columns to your intake spreadsheet).
    

### How to Request Changes

Simply make an enquiry detailing what has changed in your workflow. We will review the existing script, discuss the tailored requirements, and provide a new indicative starting price for the update before any coding begins.
