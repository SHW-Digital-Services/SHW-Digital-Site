While we advertise clear starting prices for websites, automations, and Active Directory setups, businesses often face unique challenges that don't fit neatly into a box.

### The Feasibility Study

If you have a complex idea—such as building a bespoke internal web application from scratch or connecting three obscure, outdated software systems—we will usually start with a Feasibility Study.

During this phase (which carries a small, fixed fee), we will research the APIs, investigate the technical roadblocks, and provide you with a comprehensive architecture document. This document will tell you definitively if the project is possible, how long it will take, and exactly what it will cost to build.
